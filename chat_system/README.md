# 💬 Chat System

Система для общения с обученной моделью с поддержкой памяти, автоопределения имени/настроения и обучения.

## 🚀 Быстрый старт

### 1. Установка
```
Дважды кликните: install.bat
```

### 2. Запуск
```
Дважды кликните: start.bat
```

### 3. Использование
Откройте в браузере: http://127.0.0.1:8000

---

## 📋 Функции

### Чат
- Каждый пользователь имеет отдельную историю
- Автоопределение имени из сообщений
- Автоопределение настроения
- История сохраняется между сессиями

### Оценки
- 👍 — хороший ответ (добавляется в RAG + датасет для обучения)
- 👎 — плохой ответ (помечается, не используется)
- ✏️ — исправить ответ (исправление идёт в RAG + датасет)
- 🔄 — сгенерировать другой вариант

### RAG (мгновенная адаптация)
- Положительно оценённые ответы сразу влияют на генерацию
- Исправления сразу учитываются
- Система ищет похожие ситуации и показывает модели как отвечать

### Обучение
1. Оценивайте ответы (👍/👎) и исправляйте плохие
2. Нажмите "Экспорт для обучения" во вкладке "Обучение"
3. Загрузите файл на RunPod
4. Запустите обучение (инструкция в системе)
5. Скачайте новую модель и замените в Ollama

## ⚙️ Настройки

Редактируйте файл `config.py`:

```python
# Имя модели в Ollama
MODEL_NAME = "mymodel"

# Персонаж
CHARACTER_NAME = "Анна"
CHARACTER_AGE = "28"
CHARACTER_DESCRIPTION = "..."

# Порт сервера
PORT = 8000
```

## 📁 Структура данных

```
data/
├── chroma/          # Векторная база RAG
├── database.db      # SQLite база (пользователи, сообщения, оценки)
├── exports/         # Файлы для обучения
└── logs/            # Логи
```

## 🔧 Требования

## 📝 API

Система предоставляет REST API:

- `POST /chat` — отправить сообщение
- `POST /rate` — оценить ответ
- `POST /correct` — исправить ответ
- `GET /history/{user_id}` — история
- `GET /profile/{user_id}` — профиль
- `POST /export` — экспорт для обучения
- `GET /stats` — статистика

## ❓ Решение проблем

**Модель не отвечает:**
- Проверьте что Ollama запущен: `ollama list`
- Проверьте модель: `ollama run mymodel`

**Ошибка ChromaDB:**
- Удалите папку `data/chroma` и перезапустите

**Порт занят:**
- Измените PORT в `config.py`
